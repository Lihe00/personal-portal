# personal-portal

Lihe's personal portal website

## Features

- 🏠 **Home** - Personal introduction with animated hero section
- 📝 **Notes** - Write and save personal notes with localStorage
- 🎮 **Games** - Mini games section
- 🔧 **Tools** - Calculator, Countdown Timer, Random Picker
- ℹ️ **About** - Information about this website

## Tech Stack

- HTML5
- CSS3 (Glass Morphism, Animations)
- JavaScript (Vanilla)
- localStorage for data persistence

## Usage

Simply open index.html in any modern web browser.
